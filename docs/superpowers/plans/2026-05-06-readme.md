# BioTracker

BioTracker is a personal health tracking web app for recording, reviewing, and summarizing health metrics in one place.

It is currently a local-first, manual-first MVP built to help organize day-by-day measurements such as weight, body composition, blood pressure, sleep, heart rate, steps, and personal notes. The project is designed so future device and import integrations can be added without changing the core data model.

## Current MVP

- Manual daily health entry
- Dashboard with latest daily values
- Entry history with review and edit flow
- Daily, weekly, and monthly report summaries
- Settings for preferred units and preferred metric sources
- Local JSON export/import for health data backup
- Local persistence through browser storage

## Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- React Router
- React Hook Form
- Zod
- Recharts
- Vitest + React Testing Library

## Getting Started

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Run the full test suite

```bash
npm test
```

### Run a single test file

```bash
npm test -- src/lib/storage/healthStorage.test.ts
```

## Project Structure

- `src/app/` — app bootstrap, router, shell, and navigation
- `src/features/` — feature-first route and UI code such as home, entry, history, reports, and settings
- `src/lib/` — shared date helpers, validation, storage, and report logic
- `src/types/` — shared domain model types

## Product Principles

- Manual-first workflows before device integrations
- Future-ready support for multiple data sources per metric
- Personal tracking only — not medical advice

## Current Status

BioTracker is in active MVP development. The core flows are implemented and runnable locally, with ongoing work focused on polish, consistency, and trend visualization.

## Contributing

Contributions are welcome. Before opening changes, run the local test suite and build so behavior stays aligned with the current app state.
